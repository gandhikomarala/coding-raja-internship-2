# SoundPulse Studio — Digital Audio Waveform & Spectrum Visualizer

Web Audio API studio with live microphone input and synth oscillators, fast Fourier transform (FFT) frequency spectrum bars, circular oscilloscope, gain/reverb master controls, and audio capture.

## Product Highlights
- **Domain**: Audio / Multimedia
- **Visual Theme**: Dark Synth & Spotify Lime Neon
- **State Persistence**: Browser localStorage & FastAPI microservices
- **Zero-Dependency Web Client**: Works seamlessly on GitHub Pages

## Architecture & Quick Start
```bash
# Run Tests
pytest tests/

# Docker Deployment
docker-compose up -d --build
```
